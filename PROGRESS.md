## Active work

The governed web application now has an opt-in local synthetic sign-in flow. It stores only a signed HttpOnly role session in the browser, maps that role to a bearer header only on the server, and leaves FastAPI as the final authorization authority. The presentation layer continues to use frozen snapshot read models, typed paginated collateral sections, immutable governance timeline events, secure bounded evidence renditions, and fixture-backed end-to-end verification. No browser calculation or unauthenticated document-byte exposure is permitted.
