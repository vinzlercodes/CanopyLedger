# Support

CanopyLedger is an open-source reference implementation. For installation, demonstration, and
integration help, start with the [README](README.md), [demo guide](DEMO.md), and
[versioned API contract](docs/api/openapi-v1.json).

Use GitHub Discussions or Issues for reproducible questions and feature ideas. Please search existing
threads first and include your operating system, Python and Node.js versions, the command you ran,
and a sanitized error message.

Do not use public support channels for security issues, credentials, real financial data, or sensitive
documents. Follow the [security policy](SECURITY.md) for vulnerability reports.
