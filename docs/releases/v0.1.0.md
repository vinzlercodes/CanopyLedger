# CanopyLedger v0.1.0

This open-source reference release delivers a complete governed reporting workflow for synthetic,
coffee-backed trade-finance decisions.

- Immutable canonical report models and deterministic HTML/PDF artifacts.
- Current-approved final-decision report eligibility with replayable snapshot, bundle, stage, approval,
  renderer, font, and digest lineage.
- Typed report APIs and a read-only Reports workspace that does no browser-side authority calculation.
- A one-command synthetic PostgreSQL 17/PostGIS demonstration: evidence approval, frozen snapshot,
  collateral and risk outputs, climate and credit-advisory outputs, independent approval, report
  package, API, and web UI.

The release contains synthetic data only. Climate/EUDR output remains evidence readiness, not a legal
compliance conclusion; credit early warning remains advisory and cannot alter CBB, IRC, or approvals.

Run [the demo guide](../../DEMO.md) to explore the system. Release verification is recorded in
[the release checklist](../release-checklist.md).
