# Security Policy

CanopyLedger is a non-production reference implementation. Do not use real borrower, farmer, credential, or proprietary market data.

Report vulnerabilities privately through the repository security-advisory channel once a public remote exists. Until then, contact the repository owner without opening a public issue.

Secrets belong in environment variables. `.env`, private keys, and credentials are ignored. Never commit live trading, banking, model-provider, or regulatory-system credentials.
